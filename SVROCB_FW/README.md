# SVROCB 펌웨어 (로드셀 컨트롤 보드 SVROCB_V1, ATmega8A-AU 16MHz)

로드셀(100g) 5채널의 무게를 측정합니다. 무게가 감지되면 해당 스테이션 LED(1ST~5ST)를 켜고, RS485(Modbus RTU)로 메인보드에 무게와 상태를 보냅니다.
보드 2장(DIP ID 0 = Load Cell 1~5, ID 1 = Load Cell 6~10)을 RS485 한 라인에 연결하고, 메인보드가 주소별로 읽어 갑니다.

## 빌드 (Microchip Studio)
1. New Project → GCC C Executable Project → Device **ATmega8A**
2. 생성된 main.c를 이 `main.c`로 교체하고 `define.h`를 추가
3. **Fuse**: 외부 크리스탈 16MHz, BOD 4.0V
   - LOW = `0x3F` (CKSEL=1111, SUT=11, BODEN, BODLEVEL 4.0V)
   - HIGH = `0xC1` (CKOPT 프로그램(16MHz에 필요), EESAVE 프로그램(칩 지울 때 교정값 유지))

명령줄 빌드 확인: `avr-gcc -mmcu=atmega8a -Os -Wall main.c` → Flash 약 4.8KB / RAM 약 415B

## 핀 맵 (회로도 SVROCB_V1 기준)
| 기능 | 핀 | 동작 |
|---|---|---|
| L/C_ADC1~5 | PC0~PC4 (ADC0~4) | INA155 ×50 (R 0Ω 실장) → MCP6242 ×11 |
| AREF | DC5V 직결 | ADMUX REFS=00 (외부 AREF)로 사용 |
| STATE LED D1 | PC5 | LOW = ON |
| L/C_1ST~5ST LED D2~D6 | PD3, PD4, PD5, PD6, PD7 | LOW = ON |
| RS485 RxD / TxD | PD0 / PD1 | MAX485 RO / DI |
| RS485_Drive (DE,/RE) | PD2 | HIGH = 송신 |
| COM_ID_1~3 (DIP J10) | PB0~PB2 | ON = LOW, ID = 0~7 |
| SW2 Tact | /RESET | 누르면 리셋 (전원 투입 영점이 다시 실행됨) |

## 동작
1. 전원 투입: STATE LED가 켜지고 스테이션 LED 1ST→5ST가 순서대로 깜빡입니다(점검). EEPROM에서 영점/스팬/설정을 읽습니다.
2. ADC: 1ms 타이머에서 2ms마다 ADC0~4를 연속 변환합니다. 100ms 동안 50회 합산한 값(raw 0~51150)을 다시 8개로 이동평균합니다(0.8초).
3. 무게(0.1g) = (raw − 영점) × 100.0g / 스팬. 스팬은 100.0g일 때의 raw 변화량입니다. 로드셀을 반대로 결선했으면 스팬이 음수로 저장되므로 그대로 사용할 수 있습니다.
4. 전원 투입 3초 후 **전원 투입 영점**: 저장된 영점 기준 ±20.0g 이내(또는 영점이 아직 없으면)인 채널은 현재값을 영점으로 씁니다(RAM만, EEPROM에는 저장 안 함). `ZERO_AT_POWERON 0`으로 끌 수 있습니다.
5. 감지: 무게 ≥ DETECT_ON(초기 5.0g)이면 감지, < DETECT_OFF(초기 3.0g)이면 해제(히스테리시스).
6. 스테이션 LED
   - AUTO(초기값): 감지된 채널 ON, 센서 이상 채널은 0.5초 점멸
   - MANUAL: 메인보드가 쓴 LED_MANUAL 비트대로 켜기/끄기
7. 센서 이상: ADC 값이 5 이하 또는 1018 이상인 상태가 1초 계속되면(단선, 포화) 에러 비트를 켜고, 정상으로 1초 지나면 해제합니다.
8. STATE LED(D1): 영점 전 켜짐 / 센서 이상 100ms 점멸 / 통신 정상 500ms 점멸 / 5초간 통신 없음 1초 점멸
9. 워치독 1초

## 통신 (Modbus RTU 슬레이브)
- **9600 8N1**, 슬레이브 주소 = **DIP 값 + 1** (DIP 0 → 주소 1(LC1~5), DIP 1 → 주소 2(LC6~10))
- FC03/FC04 읽기(한 번에 최대 32개), FC06/FC16 쓰기. 주소 0(브로드캐스트)으로 쓰면 모든 보드가 처리하고 응답하지 않습니다(예: 전체 영점).
- 프레임 끝: 수신이 5ms 동안 없으면 끝. 응답은 2ms 뒤에 보냅니다(`MB_TX_DELAY`).
- CRC 에러나 다른 주소의 요청에는 응답하지 않습니다. 잘못된 기능/주소/값에는 예외 응답 01/02/03을 보냅니다.

| 주소 | 내용 | R/W |
|---|---|---|
| 0~4 | 무게 CH1~5 (0.1g, signed) | R |
| 5 | 감지 bit0~4 | R |
| 6 | 에러: bit0~4 센서 이상, bit8~12 과부하(120.0g 이상) | R |
| 7 | 보드 ID (DIP 0~7) | R |
| 8 | CH1의 로드셀 번호 (ID0 → 1, ID1 → 6) | R |
| 9 | FW 버전 (100 = v1.00) | R |
| 10~14 | raw CH1~5 (0~51150) | R |
| 20 | LED_MODE 0=AUTO, 1=MANUAL (저장) | R/W |
| 21 | LED_MANUAL bit0~4 (저장 안 함) | R/W |
| 22 | DETECT_ON 0.1g (1~1000, 저장) | R/W |
| 23 | DETECT_OFF 0.1g (1~1000, 저장) | R/W |
| 24 | CAL_WEIGHT 스팬 교정 분동 0.1g (100~1200, 저장) | R/W |
| 25 | CMD (처리 후 0) | R/W |
| 26 | CMD 결과 0=OK, 1=실패(센서 이상/변화량 부족), 2=알 수 없는 명령 | R |
| 30~34 | 영점 raw CH1~5 | R |
| 35~39 | 스팬 raw CH1~5 (100.0g 기준) | R |

### 명령 (주소 25)
| 값 | 내용 |
|---|---|
| 1~5 | CH1~5 영점 (빈 상태에서) |
| 9 | 전체 영점 |
| 11~15 | CH1~5 스팬 교정 (CAL_WEIGHT 분동을 올린 상태에서) |
| 19 | 전체 스팬 교정 |
| 90 | 교정/설정 초기화 (영점 = 현재값, 스팬 = 기본값) |

### 교정 순서
1. 빈 상태에서 CMD = 1~5(또는 9) → 영점
2. 주소 24에 분동 무게 쓰기 (예: 50.0g → 500)
3. 분동을 올리고 1초 이상 기다린 뒤 CMD = 11~15 → 스팬
4. 결과는 주소 26에서 확인합니다. 교정값은 EEPROM에 저장됩니다.

## 확인 / 조정이 필요한 항목
1. **메인보드 프로토콜**: 흐름도와 회로도에 RS485 프로토콜 정의가 없어서 Modbus RTU 9600으로 정했습니다. 메인보드 쪽 규격이 따로 있으면 `define.h`의 통신 설정과 `fcModbusProcess()`만 바꾸면 됩니다.
2. **스테이션 LED의 의미**: 문서에 정의가 없어서 "무게 감지 = ON"(AUTO)으로 하고, 메인보드가 직접 제어하는 MANUAL 모드도 넣었습니다.
3. **Vref(3296 가변저항)**: 무부하일 때 L/C_ADC 출력이 약 0.3~0.5V가 되도록 맞추세요. 0V나 5V에 붙으면 센서 이상으로 판단합니다.
4. **INA155 이득**: R1/R9/R21/R27/R33(0Ω)을 실장하면 ×50, 빼면 ×10입니다. 2단 귀환저항(R2/R10/R22/R37/R30)은 33K입니다(TAL221 100g 기준 1g당 약 27mV). 초기 스팬 `DEF_SPAN`(27520)은 실측값(0g 0.30V, 32g 1.16V)으로 정했습니다. 채널마다 정확한 값은 스팬 교정으로 맞춥니다.
5. **Tact 스위치(SW2)**: /RESET에 연결되어 있어 펌웨어에서 입력으로 쓸 수 없습니다. 누르면 리셋되면서 전원 투입 영점이 다시 실행됩니다.
6. RS485 종단저항 R41(120Ω)은 라인 끝 보드에만 실장하세요.
